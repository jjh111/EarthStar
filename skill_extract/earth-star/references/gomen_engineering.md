# Gomen Engineering Specifications `[D]`

**Register:** everything in this file is a *design proposal* — engineering intent, not
built hardware. Write "would," "targets," "is designed to." Never "does." The full
protocol for keeping that line honest lives in the `earth-star-research` skill.

Load this reference when designing waste-metabolizing agents, sizing an intervention,
or translating a waste stream into a Gomen deployment brief. The core SKILL.md carries
the Gomen ontology (physical / behavioral / ethical properties); this file carries the

## Waste Taxonomy (Target Identification)

- **Metabolic**: food, energy, material flows
- **Informational**: data exhaust, communication noise, unverified claims
- **Emotional**: unprocessed trauma, stagnant grief
- **Structural**: institutional rigidity, bureaucratic friction
- **Temporal**: waiting time, coordination delays
- **Physical**: microplastics, styrofoam, batteries, derelict satellites

Prioritize by **harm potential × volume × accessibility**, then check leverage: can this
waste be metabolized, what byproducts result, and does the intervention raise ∇(𝒞) at
every scale it touches?

## Scale-Specific Deployment

- Antibodies for microplastic removal from blood

**Macro (visible-scale)**

**Network (system-scale)**

## Resonance Feedback Loop

```
Intervene → Measure ∂𝒞/∂t → Adjust → Propagate → LISTEN
```

The listening step is the whole loop. Systems tell you if healing is occurring. If a
beach ecosystem forms in the garbage patch, don't vacuum it up — adapt. And measure
with real proxies (see "Measuring ∇(𝒞) Honestly" in SKILL.md), never an invented score.

## Gomen Design Checklist

Before a Gomen brief ships, it should state:

1. The **waste class** and the **scale(s)** it operates at
2. The **metabolic pathway** (which repertoire move, what byproducts)
3. The **life-serving constraint** — what it will refuse to build
4. Its **obsolescence condition** — how it accepts being replaced (death-acceptance
   hardcoded; see Pattern 4 in SKILL.md)
5. Its **∇(𝒞) proxies** — which real measurements would show it working, per scale
6. Its **register** — `[D]` throughout, with any borrowed `[E]`/`[H]` cited
