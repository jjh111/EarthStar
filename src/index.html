II Five scales and what tends each

Heal one scale and the pattern echoes through the rest. What tends each one is a Gomen.

A Gomen is industry run in reverse. Where a factory takes ground and returns waste, a Gomen would take waste and return ground: soil, clean water, open sky. It would be grown, not manufactured — fungus for a body plan, bacteria for a gut, carbon drawn from the air for bone, sunlight for a pulse. Not a machine and not quite an animal: a new branch of life that answers to the Earth rather than to an owner, apologises as it works, and steps aside when something better grows. Each here is a design, not yet a device. Wake one.
